¡Gracias por tu interés en contribuir a EquiBot! 

Queremos que este sea un proyecto colaborativo y abierto. Si tienes sugerencias, mejoras o simplemente encuentras un error, te invitamos a contribuir siguiendo estas pautas:

### 💡 Ideas para contribuir
- Sugerir mejoras a la interfaz
- Reportar sesgos no detectados
- Proponer nuevos conjuntos de datos para reentrenamiento
- Mejorar el rendimiento o eficiencia del modelo

### 📊 Requisitos
- Clona el repositorio
- Crea una rama (`git checkout -b nombre-feature`)
- Realiza tus cambios con buenas prácticas
- Asegúrate de que la app siga funcionando localmente

### 🔁 Pull Requests
Por ahora, el equipo no revisa pull requests de forma regular, pero puedes abrir uno para dejar registrada tu contribución o sugerencia. Usaremos ese historial para futuras integraciones.

### 📧 Contacto
Puedes escribirnos directamente a: [equipo@equibot.cl](mailto:contacto@equibot.com)

Gracias por ser parte de un proyecto que pone la inteligencia artificial al servicio de la equidad ❤️
